## Open Source Projects

### 📚 mkdocs-typer2

<ProjectStats repo="syn54x/mkdocs-typer2" pypi="mkdocs-typer2" />

[mkdocs-typer2](https://github.com/syn54x/mkdocs-typer2) is a widely adopted MkDocs plugin (115k+ PyPI downloads, [listed in the MkDocs catalog](https://github.com/mkdocs/catalog)) that auto-generates CLI reference docs from Typer apps — including animated terminal `--help` output via termynal. A maintained successor to the unmaintained `mkdocs-typer` plugin; supports MkDocs and Zensical.

### 🦀 Ferro ORM

<ProjectStats repo="syn54x/ferro-orm" pypi="ferro-orm" />

[Ferro ORM](https://github.com/syn54x/ferro-orm) is an async Python ORM with a Rust core (SQLx/Sea-Query via PyO3) — Pydantic schemas, GIL-free row hydration, and an identity map for object consistency. Single runtime dependency; ships pre-built wheels for macOS, Linux, and Windows.

### ⏱️ TTD

<ProjectStats repo="syn54x/ttd" pypi="ttd-ledger" />

[TTD](https://github.com/syn54x/ttd) is a terminal-first time tracker, reporting, and invoicing tool for solo developers — natural-language logging, a full-screen Textual TUI, client-ready PDF invoices, and a Typer CLI for everything. Built on [Ferro ORM](https://github.com/syn54x/ferro-orm).
